# Hirun Afreen Portfolio

Red/black responsive portfolio with scroll reveal animations and reading progress bar.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository named `hirun-afreen-portfolio`.
2. Upload `index.html`.
3. Go to Settings → Pages.
4. Under Build and deployment choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save. Your site will be available at the GitHub Pages URL shown there.
